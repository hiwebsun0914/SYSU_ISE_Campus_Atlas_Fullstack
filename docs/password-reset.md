# 密码重置申请

用户在登录页「忘记密码？申请重置」填写账户名、姓名、学号与说明。页面提示「微信私聊奶小龙学长」。管理员通过已有微信会话或线下资料核实身份，不能仅凭姓名、学号或申请编号批准。

超级管理员在用户权限页的「密码重置申请」填写核实备注后批准，也可填写原因拒绝。普通审核员无此权限，超级管理员账号不能走本流程。批准不改变密码；返回的一次性链接应由管理员手动发给已核实的本人，不自动发送微信消息。

待审批申请 24 小时有效；同一账号仅保留一个有效待处理申请，10 分钟内不能重复提交。为避免泄露账号是否存在，未知账号、超管账号和重复申请也会收到统一提示与回执编号；这种回执不会新增有效申请，管理员按账户名核对已有记录。

批准后链接 30 分钟有效。重发仅适用于已批准的申请，重新签发会使旧链接失效；有新的有效申请时必须处理新申请。链接只在签发窗口中显示，关闭或刷新后需要重新签发。拒绝原因通过微信告知本人。

用户使用链接设置新密码后，旧密码与旧登录令牌失效。新登录令牌包含账号的 tokenVersion。数据库只保存密码哈希和链接令牌的 SHA-256 摘要，不存明文密码或完整链接。申请、审批备注与历史保存在对应用户的 passwordResetRequests 中，密码与凭证消费通过同一次原子文件替换保存。该实现沿用现有单进程 users.json 存储架构。

## 部署

需要同时发布前端和后端，尤其是 app.js、middleware/auth.js、routes/passwordReset.js。仅更新本地前端且仍连接旧云端接口时，申请和审批不可用。

`PASSWORD_RESET_PUBLIC_URL` 为接收重置链接的网站地址，默认使用宣传域名 `https://sysuzgxytj.top`。本地隔离测试可设置为本地前端地址；不能把 localhost 链接发给真实用户。`hiwebsun.top` 只作为兼容访问域名。

公共提交接口在单进程内每个来源地址限制 10 分钟 20 次请求。云端 Nginx 必须如现有配置一样从本机代理并覆盖 X-Real-IP。非本机代理部署需要调整可信代理规则；限流计数会在服务重启时清空。

测试：在 services/weapp-auth-server 运行 npm test；前端在 apps/web-h5 运行 npm run build。
